# 🌐 Python Web Scraping – Quotes Extraction
A beginner-friendly web scraping project developed using **Python, Requests, and BeautifulSoup** as part of my Python Developer Internship at Coding Samurai.
The project extracts quotes and their corresponding authors from a publicly available website and stores the collected information in a structured CSV file.

## 📌 Project Overview
Web scraping is a technique used to extract information from websites.
In this project, Python is used to fetch webpage content, BeautifulSoup is used to parse HTML, and the CSV module is used to save the extracted information.
**Website:** [Quotes to Scrape](https://quotes.toscrape.com/)

## 🎯 Project Objectives
* Fetch HTML content from a website.
* Parse HTML using BeautifulSoup.
* Extract quotes and their authors.
* Store the extracted information in a CSV file.
* Understand the basic web scraping workflow.

## 🛠️ Technologies Used
| Technology    | Purpose                         |
| ------------- | ------------------------------- |
| Python 3      | Programming language            |
| Requests      | Fetch webpage content           |
| BeautifulSoup | Parse and extract HTML elements |
| CSV           | Store extracted data            |
