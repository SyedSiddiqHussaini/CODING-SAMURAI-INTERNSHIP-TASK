# 🎯 Python Number Guessing Game
A simple graphical Number Guessing Game developed using **Python and Tkinter** as part of my Python Developer Internship at Coding Samurai.
The application generates a random number, and the user has five attempts to guess the correct number.

## 📌 Project Overview
This project demonstrates basic GUI development using Python's Tkinter library.
Users enter their guesses through a graphical interface and receive hints indicating whether their guess is higher or lower than the randomly generated number.

## ✨ Features
* Graphical User Interface (GUI).
* Random number generation between 0 and 10.
* Five guessing attempts.
* Higher and lower hints.
* Instant feedback after submitting a guess.
* Win and loss messages.
* Customised GUI layout and colours.

## 🛠️ Technologies Used
* **Programming Language:** Python
* **GUI Library:** Tkinter
* **Module:** Random
