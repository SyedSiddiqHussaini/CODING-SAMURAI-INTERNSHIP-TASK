# 🧮 Simple Python Calculator
A graphical calculator application developed using **Python and Tkinter** as part of my Python Developer Internship at Coding Samurai.
The application provides a simple graphical interface where users can perform basic arithmetic operations using interactive buttons.

## 📌 Project Overview
This project demonstrates the fundamentals of Python GUI development using the Tkinter library.
Instead of entering calculations through the terminal, users can interact with the calculator through a graphical window.

## ✨ Features
* Graphical User Interface (GUI).
* Addition (+).
* Subtraction (-).
* Multiplication (*).
* Division (/).
* Clear (C) button to reset the display.
* Decimal input support.
* Interactive calculator buttons.

## 🛠️ Technologies Used
* **Programming Language:** Python
* **GUI Library:** Tkinter
* **Concepts:** Functions, Event Handling, Variables, and GUI Components.
