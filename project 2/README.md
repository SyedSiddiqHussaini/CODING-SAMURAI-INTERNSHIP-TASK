# 📝 Python Task Management App
A simple command-line Task Management Application developed using **Python** as part of my Python Developer Internship at Coding Samurai.
This application allows users to manage their daily tasks through an interactive menu. Users can add, update, delete, and view tasks.

## 📌 Project Overview
The Task Management App is designed to provide a simple way to organise daily activities.
It uses Python lists to store tasks temporarily and provides different operations through a menu-driven interface.

## ✨ Features
* **Add Tasks:** Add new tasks to your task list.
* **Update Tasks:** Modify an existing task.
* **Delete Tasks:** Remove completed or unwanted tasks.
* **View Tasks:** Display the current list of tasks.
* **Input Validation:** Handles invalid numerical inputs.
* **Error Handling:** Displays appropriate messages when tasks are not found or invalid input is entered.
* **Exit:** Close the application safely.

## 🛠️ Technologies Used
* **Programming Language:** Python
* **Concepts:** Functions, Lists, Loops, Conditional Statements, Exception Handling.
